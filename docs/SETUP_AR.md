# دليل صاحب الموقع — Amigo Cash

هذا الدليل يشرح شو لازم تجهّز لتطلق الموقع، وكيف تشغّله، وشو بتعمل بأول يوم.

## 1. الحسابات اللي لازم تفتحها

| الخدمة | ليش | ملاحظة |
|---|---|---|
| **دومين** (مثلاً amigo.cash) + **Cloudflare** | عنوان الموقع وحماية من الهجمات | |
| **استضافة الموقع**: Vercel أو Railway أو Render | تشغيل الموقع | أسهل شي Vercel |
| **قاعدة بيانات PostgreSQL**: Neon أو Supabase | تخزين الحسابات والأرصدة | فعّل النسخ الاحتياطي اليومي |
| **Resend** | إرسال الإيميلات (تأكيد الحساب، إعادة كلمة السر، ردود الدعم) | بدونها ما بتوصل إيميلات |
| **IPQualityScore** | كشف الـ VPN والبروكسي | بدونها كشف الـ VPN متوقف |
| **Google Cloud** (اختياري) | زر «الدخول بـ Google» | |
| **حسابات ناشر** عند شبكات العروض (Torox، AdGem، MyChips، RevU، BitLabs، CPAlead) | مصدر الأرباح | بيطلبوا موقع شغّال، فبتجي بعد الإطلاق التجريبي |
| **محفظة USDT / Binance** | دفع سحوبات الأعضاء | |

## 2. المتغيرات السرية على الاستضافة

انسخ الأسماء من ملف `.env.example` وحط القيم بإعدادات الاستضافة (Environment Variables)، **مو بالكود**:

- `DATABASE_URL`: رابط قاعدة البيانات
- `APP_URL`: عنوان الموقع، مثلاً `https://amigo.cash`
- `SESSION_SECRET` و`ENCRYPTION_KEY` و`CRON_SECRET`: قيم عشوائية جديدة (الأوامر لتوليدها مكتوبة بالملف). **لا تشاركها مع حدا ولا تغيّر `ENCRYPTION_KEY` بعد الإطلاق**، لأنها بتفك تشفير أسرار الشبكات والتحقق بخطوتين.
- `TRUSTED_PROXY_HOPS`: خليها `1` على Vercel وRailway.
- `RESEND_API_KEY` و`IPQS_API_KEY` و`GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET`.

## 3. أول تشغيل

1. الاستضافة بتشغّل `npm run build`. بعدها شغّل مرة وحدة: `npx prisma migrate deploy` و`npm run db:seed`.
2. افتح الموقع وسجّل حسابك العادي.
3. من الطرفية: `npm run admin:make -- your@email.com`
4. سجّل دخول من جديد، روح على **Account → Two-factor login**، امسح الرمز بـ Google Authenticator، **وفعّل النسخ الاحتياطي السحابي داخل تطبيق Google Authenticator** (سجّل دخول بحساب Google جوا التطبيق) لحتى ما تنقفل إذا ضيّعت موبايلك. وإذا انقفلت: `npm run 2fa:reset -- your@email.com`.
5. ادخل `/admin`.

## 4. ربط شبكة عروض

1. من لوحة الإدارة: **شبكات العروض** → اختر الشبكة.
2. انسخ «رابط التأكيد (Postback)» وحطه بلوحة الشبكة، وبدّل الماكروهات بماكروهات الشبكة (مثلاً `{user_id}` عند الشبكة ممكن يكون `[USER_ID]`).
3. حط «سر الـ Postback» اللي بتعطيك ياه الشبكة، واختر طريقة التوقيع اللي بتستعملها الشبكة.
4. إذا الشبكة بتعطيك جدار عروض (iframe) حط رابطه مع `{user_id}`.
5. فعّل الشبكة واضغط حفظ. جرّب «Test postback» من لوحة الشبكة، ولازم تشوف العملية بـ **سجل التأكيدات**.

## 5. مهمة مجدولة (Cron)

خلّي الاستضافة تنادي كل 10–15 دقيقة:
`GET https://amigo.cash/api/cron` مع الهيدر `Authorization: Bearer <CRON_SECRET>`.
على Vercel: Settings → Cron Jobs.

## 6. الشغل اليومي

- **السحوبات**: «قيد المراجعة» → وافق → ابعت المبلغ من محفظتك → «تم الدفع» مع رقم العملية. أو «رفض» مع السبب، والرصيد بيرجع للعضو.
- **الدعم المباشر**: الرسائل بتوصل لحالها، وردك بيوصل للعضو بالشات وبالإيميل.
- **مكافحة الاحتيال**: راجع «حسابات تحتاج انتباه» كل يوم.
- **المسابقة الأسبوعية**: يوم الاثنين أعطِ الفائزين جوائزهم من صفحة العضو → «تعديل الرصيد».
- **سجل العمليات**: كل شي بتعمله ينسجل هون.

## 7. قبل الإطلاق

- راجع الشروط وسياسة الخصوصية مع محامي بدولة الشركة.
- حل موضوع استلام فلوس الشبكات (شركة أو شريك بدولة مدعومة).
- اطلق أول شي بشكل مغلق لـ 100–300 عضو، وراقب نسبة الاستردادات بالنظرة العامة (الهدف أقل من 10%).
